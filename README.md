# tpdb_scripts
Website modifying scripts to change and improve TPDb

## Summary
I have made some scripts (with the help of AI) that can modify the look of ThePosterDB.com
I have found them to be very useful, and thought I would share them with everyone here.
Some add core functionality that greatly improves cross-referencing collections, and some are just for personal customization.

## Prerequisites
You will need to install a userscript manager extension on your browser that allows editing website code locally. Some examples (I typically use TamperMonkey or ViolentMonkey):
```GreaseMonkey
ViolentMonkey
TamperMonkey
FireMonkey
GreasePanda
ScriptPanda
```

## Installation
All the scripts here can be copy/pasted into the extension of your choice. Note that most of them will have a configuration section on top, as they may require an API code to interact with other websites.
